# Documentos e Currículos Oficiais — Luiz Benevides

- **`Luiz_Benevides_CV_PT.pdf`**: Versão em Português Brasileiro (1 página A4, ATS Friendly).
- **`Luiz_Benevides_CV_EN.pdf`**: Versão em Inglês Internacional (1 página A4, ATS Friendly).
- **`cv-pt.html`**: Arquivo-fonte semântico do currículo em português.
- **`cv-en.html`**: Arquivo-fonte semântico do currículo em inglês.
- **`tcc-blockchain-carteiras-digitais.pdf`**: TCC de conclusão do curso Técnico em Informática pelo IFMS (2023) — *Blockchain: Um Estudo Exploratório sobre Carteiras Digitais de Cripto Ativos* (Autores: Luiz Felipe Quevedo Benevides e Pedro Mirra Fernandes; Orientador: Prof. Esp. Lucas Alves dos Santos).

Ambos os PDFs de currículo foram estruturados em coluna única, sem gráficos ou tabelas complexas, com texto selecionável e rigorosamente ajustados para caberem em uma única página A4.
